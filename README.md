# PharmaRec

## Comparative Drug Recommendation System

PharmaRec is a healthcare recommendation system built to compare three popular recommendation approaches:

- Content-Based Filtering
- Collaborative Filtering
- Hybrid Recommendation

The project demonstrates how Natural Language Processing (NLP) can be combined with recommender systems to recommend drugs based on patient reviews, medical conditions, and user ratings.

---

## Features

- Drug recommendation using NLP
- Content-Based Filtering (TF-IDF + Cosine Similarity)
- Collaborative Filtering (SVD)
- Hybrid Recommendation
- Performance comparison
- FastAPI REST API
- React Frontend
